# OT/ICS Cyber Lab

My hands-on record of learning operational technology (OT) and industrial control systems (ICS) security, from networking fundamentals to defending a simulated plant.

Each folder is one stage of my learning plan. A stage is only marked complete when I can do its checkpoint tasks without following a tutorial; the evidence (diagrams, packet captures, configs, write-ups) sits in that folder.

| Stage | Focus | Status |
|---|---|---|
| [01](01-it-foundations/) | Computers and virtual machines | In progress |
| [02](02-networking/) | Networking and TCP/IP | Not started |
| [03](03-linux-windows/) | Linux and Windows administration | Not started |
| [04](04-security-fundamentals/) | IT security fundamentals | Not started |
| [05](05-industrial-automation/) | PLCs, HMI, SCADA (OpenPLC, Ignition) | Not started |

| [09](09-capstone/) | Capstone: defending a simulated plant | Not started |

See [LEARNING-LOG.md](LEARNING-LOG.md) for dated progress notes.

## Lab rules

- Everything runs in isolated virtual networks I own. Nothing here targets real equipment.
- No real plant data, credentials or customer captures are ever published.
